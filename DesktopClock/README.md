# 桌面时钟

简洁大气的桌面时钟挂件。显示公历、农历、星期、节日、节气、天气。内存占用小（约 24MB 私有内存）。

## 项目结构

```
DesktopClock/
├── DesktopClock.exe        ← 程序本体（双击即用）
├── DesktopClock.ini        ← 配置文件（自动生成）
├── README.md               ← 本说明
├── fonts/                  ← 字体（放 .ttf 即出现在字体列表）
├── src/                    ← 源码
│   ├── Program.cs          ← 主程序（界面/逻辑/设置）
│   ├── Calendar.cs         ← 农历/节气算法
│   └── Test.cs             ← 农历算法自检（测试用）
└── scripts/                ← 构建与安装脚本
    ├── build.bat           ← 重新编译 DesktopClock.exe
    ├── build-test.bat      ← 编译并运行农历算法自检
    ├── make-shortcut.ps1   ← 生成桌面快捷方式
    └── 安装到桌面.bat       ← 一键创建桌面快捷方式
```

## 运行

双击 `DesktopClock.exe` 即可。系统自带 .NET Framework 4.x，**无需安装任何环境**。

## 操作

| 操作 | 功能 |
|---|---|
| **左键拖动** | 移动时钟到任意位置（位置自动记住；开启锁定后不可拖） |
| **右键单击时钟** | 打开菜单：设置 / 锁定 / 置顶 / 穿透 / 天气 / 自启 / 退出 |
| **右键托盘图标** | 任务栏右下角的小时钟图标，功能同右键菜单 |
| **双击托盘图标** | 打开设置 |
| **右键 → 设置** | 字体、字号、颜色、位置、天气等全部可调，**实时预览** |

> 开启「鼠标穿透」后时钟不拦截鼠标，请通过**托盘图标**操作。

## 显示内容

```
  21:33  45             ← 时间（大字，可开关秒）
  ─────────             ← 强调色装饰线
  2026年8月9日 星期六      ← 公历 + 星期
  农历丙午马年 六月廿七      ← 农历 + 干支 + 生肖
  立秋                    ← 节气；当天是节日时显示节日徽章
  北京 晴 27℃ 29~21℃ 东南风1级   ← 天气（可开关）
```

## 设置说明（分页）

- **外观**：字体预设（简洁/经典/楷书/黑体/仿宋/等线/快乐），时间字体、信息字体独立选择，时间字号 28–240，文字颜色、强调色、背景颜色、背景透明度、显示秒
- **布局**：位置预设（8 个）+ 记住当前位置，**位置锁定**（防误拖），置顶，鼠标穿透
- **天气**：显示天气开关，常用城市下拉（含自动补全），支持**输入城市名搜索**（自动查城市码），也可手动输入城市名+城市码
- **常规**：开机自启

> 字体除系统字体外，`fonts` 文件夹中附带了「站酷快乐体」（可爱风，开源 OFL 授权）。把喜欢的 `.ttf` 字体放入 `fonts` 文件夹即自动出现在字体列表中。

## 天气

- 数据来自**中国天气网**（免费，无需 key），每 30 分钟自动刷新
- 三种选城市方式：
  1. **常用城市下拉**（北京、上海、广州、深圳、杭州、成都等 40+ 城市，带自动补全）
  2. **搜索城市名**：在"搜索城市"框输入城市名（如"成都""苏州"）回车或点搜索，从结果中点选，自动填好城市码并应用
  3. **手动输入**城市名 + 城市码（如北京=101010100）
- 搜索接口无法匹配时结果列表会提示，网络异常时天气行自动隐藏，不影响时钟
- 天气接口为纯 HTTP 免 TLS，规避了部分网络环境下的 SSL 指纹屏蔽问题

## 配置文件

所有设置保存在 `DesktopClock.ini`（与 exe 同目录），可直接编辑。

## 开机自启

设置里勾选「开机自启」，或右键菜单开启。写入注册表 `HKCU\...\CurrentVersion\Run`。

## 常见问题

- **鼠标穿透后无法操作**：用任务栏右下角的托盘时钟图标（右键）恢复。
- **文字发虚**：本程序不声明 DPI 感知以兼容系统缩放；若在高缩放下发虚，可调大时间字号。
- **想加更多字体**：把 `.ttf` 放进 `fonts` 文件夹即可，无需改代码。
- **重新编译**：`build.bat`（主程序）、`build-test.bat`（农历/节气算法自检）。

## 算法说明

- 农历：经典查表法（1900–2100 年历表），含闰月、大小月；13 项已知日期断言自检通过
- 节气：天文近似公式，精确到日
- 节日：农历节日 + 公历节日 + 清明
